# Bidyut Mondal — Personal Portfolio

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Before publishing

1. Replace `your.email@example.com` in `src/App.jsx`.
2. Replace the GitHub and LinkedIn placeholder links.
3. Add your real `resume.pdf` inside the `public` folder.
4. Replace project `github` and `demo` links with your actual links.
5. Update education details when ready.

## Build

```bash
npm run build
```
